### 前文
本使用許諾契約書(以下「本契約」といいます)は、\*nao\*(以下「開発者」といいます)が提供するソフトウェア「ゆかりねっとコネクターNEO」(以下「本ソフトウェア」といいます)の利用条件を、本ソフトウェアを利用するすべての方(以下「利用者」といいます)と開発者との間で定めるものです。
利用者は、本ソフトウェアをインストールまたは利用する前に本契約をお読みください。第13条の方法で同意した方のみ、本ソフトウェアを利用できます。

### 第1条 定義
本契約では、次の用語を次の意味で使います。

1. 「本ソフトウェア」：ゆかりねっとコネクターNEO のプログラム、インストーラ、プラグイン、関連する文書およびその更新版をいいます。

2. 「外部サービス」：本ソフトウェアが連携する第三者のクラウドサービス、翻訳 API、音声認識 API、UDトークなどをいい、主なものを別表2に示します。

3. 「共用サーバ」：開発者が運用するサーバ(共用翻訳サーバ、言語推定サーバ、支援モードの中継サーバなど)をいい、別表1に示します。

4. 「同時導入ソフトウェア」：第3条に定める Microsoft 社のランタイム類をいいます。

5. 「入力データ」：利用者が本ソフトウェアに入力し、または本ソフトウェアが取得する音声、文字起こし結果、翻訳対象の文字列、会話の記録などをいいます。

6. 「外部送信」：本ソフトウェアまたは開発者が提供するウェブページが、利用者の PC に記録された情報(入力データ、本ソフトウェアの版、端末を識別するための番号など)を、利用者以外の者のサーバへ送ることをいいます。

### 第4条 外部送信と通信するデータの取扱い

1. 本ソフトウェアは、機能を提供するために外部サービスおよび共用サーバへ接続し、翻訳対象の文字列、音声その他の入力データを送受信します。送信先、送信する情報、その目的は別表1・別表2のとおりです。最新の一覧は次のページで公表します。本契約の別表とこのページが食い違う場合は、このページの記載が新しいものです。

    <https://nmori.github.io/yncneo-Docs/support/external-transmission/>

2. 利用者が自分で用意した API キーを使う場合でも、次の場合には、入力データの一部を共用サーバへ送信することがあります。
    * 利用者が選んだ翻訳エンジンで翻訳に失敗したとき。「代わりの翻訳」に選んだエンジン(既定は共用翻訳サーバ)へ送ります。「代わりの翻訳」を「翻訳しない」または PC の中で動く翻訳にすると、この送信は止まります。
    * 翻訳サーバ、Twitch のチャット翻訳、MCP サーバなどのプラグインが言語の判定を求め、PC の中の判定だけでは言語が決まらないとき(言語推定サーバ)。

    「音声と翻訳」の「翻訳する言語」の画面にある「共用サーバを使わない (オプトアウト)」をオンにすると、前2つの送信はどちらも止まります。このとき本ソフトウェアは、共用翻訳サーバへは送らずに翻訳の失敗として扱い、言語の判定は PC の中の判定だけで行います。翻訳エンジンに共用翻訳サーバを選んでいる欄は、訳が出なくなります。オンにしても本ソフトウェアは動きますが、翻訳の精度が下がることがあります。支援モード(第7条)の翻訳はこの設定の対象外です。

3. 本ソフトウェアは、共用サーバへの通信に本ソフトウェアの版を付けて送り、開発者はそれを版ごとの利用件数の集計と障害の調査に使います。

4. 外部サービスに送信されたデータは、各提供者の利用規約およびプライバシーポリシーにより取り扱われます。利用者は、これらを確認したうえで外部サービスを利用するものとします。

5. 共用サーバに送信された入力データは、翻訳・言語推定などその機能の処理のためにのみ使用し、処理後に保存しません。ただし、通信の日時、送信元の IP アドレス、ヘッダ、本ソフトウェアの版など通信の記録は、共用サーバを置いているクラウドの記録として 365日間残ります。

6. 支援モード(第7条)で翻訳するときは、入力データは開発者の中継サーバを通り、開発者が契約している翻訳サービス(別表1に記載)へ送られます。

7. 利用者は、外部サービスの利用規約に反しない方法で本ソフトウェアを使用します。利用者自身の API 契約に基づく料金や利用上限は、利用者が管理します。

#### 支援モードの中継サーバ
* 置き場所：Cloudflare(Workers)
* 送信する情報：支援モードのコード(登録のときだけ)、登録時に作る端末の番号と署名(登録しているときは起動時にも送ります)、翻訳・判定の対象の文字列、翻訳元と翻訳先の言語
* 目的：支援者の確認、月ごとの使用量の計算、開発者が契約するサービスへの中継。中継先は Google Cloud Translation、Microsoft Translator、DeepL、NAVER Papago、OpenAI、Amazon Translate(東京・フランクフルト)、Amazon Comprehend(文の感情の判定)です

#### ウェブ音声認識のページ(yukari-connect.app)
* 送信する情報：ページを開いたときの通常の通信の情報(IP アドレス、ブラウザの種類、ページの URL に入った接続先のポート番号と言語)
* 目的：ページの表示
* このページの字体は開発者のサーバに置いたものを使い、第三者のサーバからは読み込みません。音声の認識はブラウザ(Google Chrome など)の音声認識機能で行います。音声はブラウザの提供者のサーバへ送られ、その提供者のプライバシーポリシーにより取り扱われます。

#### 字幕共有の閲覧ページ(yukari-connect.app)
* 送信する情報：ページを開いた人の通常の通信の情報
* 目的：ページの表示(字幕の受け渡しは、利用者が自分で作った Pusher のアプリを通ります)

#### お知らせ・NG ワード辞書・更新確認(machanbazaar.com、nmori.github.io)
* 送信する情報：取得のための通常の通信の情報(IP アドレス、本ソフトウェアの通信であること)
* 目的：お知らせ、NG ワード辞書、更新版の有無の取得

#### DeepL の用語集の準備(DeepL SE)
* 送信する情報：用語集に登録した語句、翻訳元と翻訳先の言語、API キー
* 目的：DeepL で翻訳するときの用語集の作成(利用者自身の DeepL キーを使うとき、または支援の段階が 3 以上のとき)

#### 不具合の報告(Discord)
* 送信する情報：利用者が「不具合を知らせる」を押したときの報告の内容
* 目的：開発者への不具合の報告(押したときだけ)

#### 時刻の確認(yukari-connect.app)
* 送信する情報：通常の通信の情報(IP アドレスなど)。内容は送りません
* 目的：PC の時計のずれの確認

#### インフォグラフィックス用サーバ(Google Cloud Run)
* 送信する情報：登録した利用者の番号と鍵、認識した文字列
* 目的：インフォグラフィックスの作成(プラグインを使い、登録したときだけ)

### 別表2 主な連携先の外部サービス
各サービスへは、利用者がその機能を有効にした場合に接続します。送信する情報は主に翻訳・認識の対象の文字列または音声で、利用者が設定した API キーなどの認証情報を添えます。

#### 翻訳・生成 AI
* Microsoft Translator・Azure(Microsoft Corporation)、Google Cloud Translation・Gemini(Google LLC)、Amazon Web Services(Amazon Web Services, Inc.)、DeepL(DeepL SE)、NAVER Papago(NAVER Cloud Corp.)、Tencent Cloud(Tencent)、百度翻訳(Baidu)、Alibaba Cloud(Alibaba Cloud)、PLaMo(株式会社 Preferred Networks)、みんなの自動翻訳(国立研究開発法人 情報通信研究機構)、OpenAI API(OpenAI)、Anthropic API(Anthropic PBC)、xAI API(xAI)、OpenRouter(OpenRouter, Inc.)

#### 音声認識
* UDトーク(Shamrock Records株式会社)、各翻訳・AI 事業者の音声認識 API
* UDトークから受けた発話に言語が付いていないときは、その発話の先頭の 10 文字ほどを Google LLC の言語判定 API へ送り、言語を判定します。

#### 配信・連携
* Discord、Twitch、YouTube、ニコニコ生放送、cluster、Zoom、Pusher、Slack、Microsoft Teams、Notion など、利用者がプラグインで接続を設定したサービス

#### モデルの取得
* オフライン翻訳・音声認識のモデルを取得するときは、Hugging Face と GitHub から取得します(取得のための通常の通信の情報だけを送ります)。PLaMo 3 のライセンスに同意しているときは、ライセンスの改定がないかを Hugging Face に確認します(12 時間に 1 回まで)。

#### ランタイムの取得
* インストーラは、第3条のとおり Microsoft 社のサーバから .NET・Visual C++・WebView2 のランタイムを取得します(取得のための通常の通信の情報だけを送ります)。
