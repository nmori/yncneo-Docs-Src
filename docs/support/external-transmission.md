# 外部送信について

ゆかりねっとコネクターNEO（以下「ゆかコネ」）と、この説明サイトが、**あなたの PC やブラウザから、どこへ、どんな情報を送っているか**をまとめたページです。
電気通信事業法の「外部送信規律」に沿って公表しています。使用許諾契約書（第4条）の別表と、このページが食い違うときは、このページが新しいものです。

| このページでわかること | 見るところ |
|:--|:--|
| ゆかコネが、開発者の用意したサーバへ送るもの | [1. 開発者が用意した送信先](#developer) |
| ゆかコネが、あなたが選んだサービスへ送るもの | [2. あなたが有効にしたサービス](#services) |
| この説明サイトを見たときに送られるもの | [3. この説明サイト](#website) |

!!! warning "自分の API キーを使っていても、開発者のサーバへ文字が送られることがあります"
    DeepL や Google などに**自分の API キー**を設定していても、次の 2 つのときは、話した言葉の文字が開発者の**共用サーバ**へ送られることがあります。

    * **共用翻訳サーバ**：あなたが選んだ翻訳エンジンで翻訳に失敗したとき。失敗した文は「**代わりの翻訳**」（翻訳エンジンの 5 番目の枠）で訳し直し、その既定が共用翻訳サーバです。
        * 止め方：「代わりの翻訳」を **翻訳しない** か、PC の中の翻訳（オフライン翻訳など）にします。**音声と翻訳** → **音声の入れ方** の **このパソコンの中だけで動かす** を押しても、「代わりの翻訳」は **翻訳しない** になります。
        * または、上のタブ **音声と翻訳** → **翻訳する言語** の、**母国語設定にかかわらず、他国語で話したときは母国語に逆翻訳する** のすぐ下にある **共用サーバを使わない (オプトアウト)** をオンにします（v3.2.7 から）。
    * **言語推定サーバ**：一部のプラグイン（翻訳サーバ、Twitch のチャット翻訳、MCP サーバなど）が文の言語の判定を求め、PC の中で何語か決められなかったとき。ゆかコネ本体の翻訳では使っていません（2026年10月から、PC の中だけで判定しています）。
        * 止め方：上のタブ **音声と翻訳** → **翻訳する言語** の、**母国語設定にかかわらず、他国語で話したときは母国語に逆翻訳する** のすぐ下にある **共用サーバを使わない (オプトアウト)** をオンにします（v3.2.7 から）。**このパソコンの中だけで動かす** のボタンでは止まりません。

    **共用サーバを使わない (オプトアウト)** をオンにすると、共用翻訳サーバと言語推定サーバの両方へ送らなくなります。
    オンにしても動きますが、**翻訳の精度が下がることがあります**。支援モードの翻訳（支援モードの中継サーバ）は、この設定の対象外です。

    * 共用翻訳は「代わりの翻訳」だけでなく、**翻訳1の既定**でもあります。翻訳エンジンに **共用翻訳** を選んだ欄があるままオンにすると、**その欄は訳が出なくなります**。オンにするときは、その欄の翻訳エンジンをほかのものに変えてください（オンにしたときに共用翻訳を選んだ欄があれば、ゆかコネが知らせます）。
    * オンのとき、文が何語かは、サーバへ送らずに PC の中の判定だけで決めます（かな・アラビア文字などは判定できます）。

!!! warning "共用サーバへの通信には、ゆかコネの版（バージョン）を付けています"
    共用サーバへ送るときは、いつも**ゆかコネの版**（例：3.2.6）を一緒に送ります。
    開発者は、これを**版ごとの利用件数の集計**と、障害の調査に使っています。

## 1. 開発者が用意した送信先 { #developer }

開発者が運用しているサーバ（共用サーバ）と、開発者が用意した送信先です。
サーバの置き場所は、開発者が契約しているクラウドです。

| 送信先 | 送信する情報 | 何に使うか | 止め方 |
|:--|:--|:--|:--|
| **共用翻訳サーバ**<br>運用：開発者<br>置き場所：Google Cloud（Google LLC）、Amazon Web Services（Amazon Web Services, Inc.） | 翻訳する文字、翻訳元と翻訳先の言語、**ゆかコネの版**、支援の段階 | 翻訳、版ごとの利用件数の集計、障害の調査<br>（「代わりの翻訳」の既定です。選んだ翻訳エンジンで訳せなかった文は、**自分の API キーを使っていても**ここへ送ることがあります） | 代わりの翻訳として送らないようにするには、「代わりの翻訳」を **翻訳しない** か PC の中の翻訳にします（**このパソコンの中だけで動かす** のボタンでもなります）。<br>または、**共用サーバを使わない (オプトアウト)** をオン（v3.2.7 から）。<br>共用翻訳を自分で選んでいるときは、翻訳エンジンをほかのものにします |
| **言語推定サーバ**<br>運用：開発者<br>置き場所：Google Cloud（Google LLC） | 何語かを調べる文字、**ゆかコネの版**、支援の段階 | 文が何語かの判定、版ごとの利用件数の集計、障害の調査<br>（一部のプラグイン（翻訳サーバ、Twitch のチャット翻訳、MCP サーバなど）が言語の判定を求め、PC の中で決まらなかったときだけ。**自分の API キーを使っていても送ることがあります**。本体の翻訳では使っていません） | **共用サーバを使わない (オプトアウト)** をオン（v3.2.7 から。**このパソコンの中だけで動かす** のボタンでは止まりません） |
| **感情判定サーバ**<br>運用：開発者<br>置き場所：Amazon Web Services（Amazon Web Services, Inc.） | 感情を調べる文字 | 文の感情の判定（感情の判定を求めるプラグインを使ったときだけ。ゆかコネに付いているプラグインは使っていません） | 感情の判定を使うプラグインを入れないか、止めます |
| **支援モードの中継サーバ**<br>運用：開発者<br>置き場所：Cloudflare（Cloudflare, Inc.） | 支援コード（登録のときだけ）、登録のときに作る端末の番号と署名、翻訳する文字、翻訳元と翻訳先の言語 | 支援者の確認、月ごとの使用量の計算、開発者が契約している翻訳サービス（Google Cloud Translation、Microsoft Translator、DeepL、NAVER Papago、OpenAI）への中継<br>（支援コードを登録して、支援モードの翻訳を使うときだけ） | 支援コードを登録しなければ送りません |
| **ブラウザ音声認識のページ**（yukari-connect.app）<br>運用：開発者 | ページを開いたときのふつうの通信の情報（IP アドレス、ブラウザの種類、ページのアドレスに入った接続先のポート番号と言語） | ページの表示（音声認識に「ブラウザの音声認識」を選んだときだけ） | 音声認識に、ブラウザの音声認識のほか（オフライン認識など）を選びます |
| **字幕共有の閲覧ページ**（yukari-connect.app）<br>運用：開発者 | ページを開いた人のふつうの通信の情報 | ページの表示（字幕は、あなたが作った Pusher のアプリを通ります）<br>（字幕共有を使うときだけ。送るのは、ページを開いた人のブラウザです） | 字幕共有を使わなければ送りません |
| **お知らせ・NG ワード辞書・更新の確認**（machanbazaar.com、nmori.github.io）<br>運用：開発者 | 取りに行くためのふつうの通信の情報（IP アドレス、ゆかコネからの通信であること） | お知らせ、NG ワード辞書、新しい版があるかの取得 | 止める設定はありません。新しい版や大事なお知らせを届けるための通信で、声や字幕の文字は送りません |
| **時刻の確認**（yukari-connect.app）<br>運用：開発者 | ふつうの通信の情報（IP アドレスなど）。中身は送りません | PC の時計のずれの確認 | 止める設定はありません。中身は送らず、届かないときは PC の時計のまま動きます |

!!! info "ブラウザ音声認識のページについて"
    このページの字体は、開発者のサーバ（yukari-connect.app）に置いたものを使います。
    声の認識は、ブラウザ（Google Chrome・Microsoft Edge など）の音声認識の機能で行います。
    **声はブラウザの提供者のサーバへ送られ**、その提供者のプライバシーポリシーで扱われます。

### 起動したときなどの通信 { #startup }

上の表のほかに、次の通信をします。**声や字幕の文字は送りません。**

| いつ | 送信先 | 送信する情報 | 何に使うか |
|:--|:--|:--|:--|
| 支援コードを登録しているとき | 支援モードの中継サーバ（Cloudflare, Inc.） | 端末の番号と署名 | 支援の確認 |
| DeepL の自分の API キーを使うとき、または支援 Tier 3 以上のとき | DeepL（DeepL SE） | API キー、辞書に登録した語 | 用語集の準備 |
| PLaMo 3 翻訳（オフライン）に同意しているとき（12 時間に 1 回まで） | Hugging Face（Hugging Face, Inc.） | モデルの置き場の名前 | ライセンスが改定されたかの確認 |
| **不具合を知らせる** を押したとき | Discord（Discord Inc.） | あなたが書いた報告の文 | 不具合の報告 |

### インストーラを使うとき { #installer }

インストーラは、必要な部品（.NET 10 デスクトップ ランタイム、Visual C++ 再頒布可能パッケージ、Microsoft Edge WebView2 ランタイム）が PC に無いか古いときだけ、**Microsoft Corporation** のサーバ（aka.ms、go.microsoft.com など）から取ってきます。
送るのは、取りに行くためのふつうの通信の情報です。インストールの前に自分で入れておけば、インストーラはそれを入れません。

## 2. あなたが有効にしたサービス { #services }

次のサービスへは、**あなたがその機能を選んだり、プラグインをオンにしたりしたときだけ**送ります。
送るのは主に、翻訳や認識をする**文字または声**と、あなたが設定した API キーなどの認証の情報です。
送ったあとの扱いは、それぞれのサービスの利用規約とプライバシーポリシーによります。

| 種類 | 送信先（運用する会社） | 送信する情報 | 何に使うか |
|:--|:--|:--|:--|
| 翻訳・生成 AI | Microsoft Translator・Azure（Microsoft Corporation）<br>Google Cloud Translation・Gemini（Google LLC）<br>Amazon Web Services（Amazon Web Services, Inc.）<br>DeepL（DeepL SE）<br>NAVER Papago（NAVER Cloud Corp.）<br>Tencent Cloud（Tencent）<br>百度翻訳（Baidu）<br>Alibaba Cloud（Alibaba Cloud）<br>PLaMo（株式会社 Preferred Networks）<br>みんなの自動翻訳（国立研究開発法人 情報通信研究機構）<br>OpenAI API（OpenAI）<br>Anthropic API（Anthropic PBC）<br>xAI API（xAI）<br>OpenRouter（OpenRouter, Inc.） | 翻訳する文字、言語、API キー | 翻訳、AI の応答 |
| 音声認識 | UDトーク（Shamrock Records 株式会社）<br>各翻訳・AI の会社の音声認識 API<br>ブラウザ音声認識（Chrome は Google LLC、Edge は Microsoft Corporation） | 声、または認識した文字、API キー | 声を文字にする |
| 言語の判定（UDトークを使うとき） | Google の言語判定 API（Google LLC） | UDトークから届いた文に言語が付いていないとき、その文の先頭の 10 文字ほど | 文が何語かの判定 |
| 配信・連携 | Discord、Twitch、YouTube、ニコニコ生放送、cluster、Zoom、Pusher、Slack、Microsoft Teams、Notion など、プラグインで接続を設定したサービス | 字幕の文字など、そのプラグインで送ると決めたもの、認証の情報 | それぞれの連携 |
| モデルの取得 | Hugging Face（Hugging Face, Inc.）、GitHub（GitHub, Inc.） | 取りに行くためのふつうの通信の情報だけ | オフライン翻訳・音声認識のモデルの取得 |

!!! tip "どこへ送っているかは、ゆかコネの画面でも確かめられます"
    上のタブ **ホーム** → **いまの状態** の **送り先** の行に、「声: … ／ 文字: …」と出ます。
    声も文字も PC の外へ出したくないときは、[外部と通信をしたくない場合](../v3.0/qa/network.md) をご覧ください。

## 3. この説明サイト { #website }

この説明サイト（nmori.github.io/yncneo-Docs）をブラウザで見ると、次の送信先へ情報が送られます。

| 送信先（運用する会社） | どのページで | 送信する情報 | 何に使うか | 止め方 |
|:--|:--|:--|:--|:--|
| **Google アナリティクス**（Google LLC） | すべてのページ | 見たページのアドレス、前に見ていたページ、ブラウザ・OS・画面の大きさ、IP アドレス（おおよその地域の推定に使われます）、Cookie に保存する識別子 | 見られているページの集計と、サイトの改善 | ブラウザで Cookie を止める、または [Google アナリティクス オプトアウト アドオン](https://tools.google.com/dlpage/gaoptout) を入れる |
| **Google Fonts**（Google LLC） | すべてのページ | ふつうの通信の情報（IP アドレス、ブラウザの種類、見ているページ） | 字体（Roboto）の読み込み | ブラウザの設定で Web フォントを止める |
| **BootstrapCDN**（maxcdn.bootstrapcdn.com） | すべてのページ | ふつうの通信の情報（IP アドレス、ブラウザの種類、見ているページ） | アイコン（Font Awesome）の読み込み | ブラウザの拡張機能などで読み込みを止める |
| **jsDelivr**（cdn.jsdelivr.net） | 活動メンバー・卒業メンバーのページ | ふつうの通信の情報（IP アドレス、ブラウザの種類、見ているページ） | 絵文字の画像（🔗・📺 のアイコン）の読み込み | ブラウザの拡張機能などで読み込みを止める |
| **YouTube**（Google LLC） | 利用者の声・活動レポートのページ | ふつうの通信の情報、YouTube の Cookie | 動画の埋め込み表示 | 動画のあるページを開かない |
| **Twitch**（Twitch Interactive, Inc.） | 利用者の声のページ | ふつうの通信の情報、Twitch の Cookie | 動画の埋め込み表示 | 動画のあるページを開かない |
| **note**（note 株式会社） | 利用者の声のページ | ふつうの通信の情報、note の Cookie | 記事の埋め込み表示 | そのページを開かない |

* この説明サイトに、広告はありません。
* この説明サイトは **GitHub Pages（GitHub, Inc.）** に置いています。ページを開くと、GitHub のサーバにふつうの通信の情報が届きます。
