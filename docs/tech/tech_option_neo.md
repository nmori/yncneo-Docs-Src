# NEO起動オプションについて

!!! Info "内容について"
    この内容はサービス改良の中で予告なく改定されることがあります

ゆかコネNEO（``ync_neo.exe``）は、起動時にオプションを付けることで動作を変えられます。

!!! Warning "書き方のルール"
    * 言語指定と ``/startup`` ``/log`` ``/loadall`` ``/iptalk`` ``/recovery`` は、**小文字**で、**ほかの文字とつなげず独立した引数**として渡してください。``/JA`` や ``/ja=1`` のような書き方は無視されます。
    * ``/config=`` ``/profile=`` は、前の部分（``/config`` ``/profile``）の大文字・小文字は問いません。ただし ``=`` のうしろの値はそのまま扱われます。
    * 一覧にない引数は無視されます（エラーにはなりません）。

## GUI言語の指定

* ゆかコネNEOの画面の言語を指定します。

|オプション|言語|
|:--|:--|
|``/ja``|日本語|
|``/en``|英語|
|``/es``|スペイン語|
|``/ru``|ロシア語|
|``/zh``|中国語|
|``/ko``|韓国語|
|``/pt``|ポルトガル語|
|``/fr``|フランス語|
|``/id``|インドネシア語|

* 指定しない場合は、Windowsの言語設定に従います。

=== "例）日本語"
    ```dos
        ync_neo.exe /ja
    ```
=== "例）英語"
    ```dos
        ync_neo.exe /en
    ```

## 設定フォルダの位置

* フォルダを指定します。
* ゆかコネNEOはこのフォルダを基準としてデータを読み書きします。
* 最後に ``\`` をつけるようにしてください
* 指定したフォルダが存在しない場合は自動的に作成されます。

=== "例）フォルダ指定例"
    ```dos
        ync_neo.exe /config=d:\yneneo\config\
    ```

## プロファイルを指定して起動

!!! Tech "使用条件"
    * ゆかコネNEO v2.3.13～（プロファイル機能の追加以降）

* 「設定保存・復元」画面で作ったプロファイルを、起動時に切り替えて立ち上げます。
* 場面ごとの設定（配信用・コラボ用など）を使い分けるときに便利です。

=== "例）プロファイル指定"
    ```dos
        ync_neo.exe /profile=配信用
    ```

* まずプロファイルIDと完全一致するものを探し、見つからなければ**プロファイル名の前方一致**で探します。
* 「設定保存・復元」画面の「ショートカットを作る」を使うと、このオプションが付いたショートカットを自動で作れます。

## 最小化して常駐で起動

* タスクバーに出さず、通知領域（トレイ）に常駐した状態で起動します。
* Windowsのスタートアップに登録して、パソコン起動と同時に立ち上げておきたいときに使います。

=== "例）常駐起動"
    ```dos
        ync_neo.exe /startup
    ```

!!! Tip "スタートアップ登録について"
    「起動時設定」画面の「スタートアップ登録を実行」を使うと、このオプション付きで自動的に登録されます。手で書く必要はありません。

## 調査用ログを強制的に出す

* デバッグモード（不具合調査用ログ）を有効にした状態で起動します。
* 「起動時設定」画面の「デバッグモードを有効にする」を毎回入れ直す手間を省けます。

=== "例）ログ出力ON"
    ```dos
        ync_neo.exe /log
    ```

## プラグインを読み込まずに起動する（セーフモード）

* プラグインを**一切読み込まずに**起動します。
* プラグインが原因で起動できない・動作がおかしいときの緊急用です。

=== "例）セーフモード"
    ```dos
        ync_neo.exe /safe
    ```

* ``/loadall`` と同時に指定した場合は ``/safe`` が優先されます。
* セーフモード中は、プラグインの読み込み設定を書き換えません。そのまま終了しても、次の通常起動でプラグインの構成は元のまま残ります。

!!! Tip "使い分け"
    * **起動しない・落ちる** → ``/safe`` で立ち上げて、原因のプラグインを無効にする
    * **プラグインを無効にしすぎて戻せない** → ``/loadall`` で全部読み込む

## すべてのプラグインを読み込む

* 通常は、無効化したプラグインは読み込まれません。このオプションを付けると、**その指定を無視してすべてのプラグインを読み込みます**。
* 「プラグインの設定をおかしくしてしまって元に戻せない」ときの復旧用です。

=== "例）全プラグイン読み込み"
    ```dos
        ync_neo.exe /loadall
    ```

## バックアップ・リカバリツールを起動する

* 起動時にバックアップ／リカバリのツールを開きます。
* 左右どちらかの **Shiftキーを押しながら起動**したときと同じ動作です。

=== "例）リカバリ起動"
    ```dos
        ync_neo.exe /recovery
    ```

## 文字情報保障（IPtalk）の受信を有効にする

* IPtalk からの文字情報を受け取るモードで起動します。
* 情報保障の現場で使う方向けのオプションです。

=== "例）IPtalk受信ON"
    ```dos
        ync_neo.exe /iptalk
    ```

## 組み合わせて使う

* オプションは空白で区切って複数指定できます。

=== "例）複数指定"
    ```dos
        ync_neo.exe /ja /startup /profile=配信用
    ```

!!! Info "すでに起動しているとき"
    * ゆかコネNEOが起動済みの状態で、引数を付けて起動した場合、新しく起動したほうは終了し、**引数だけが起動中のゆかコネNEOへ引き渡されます**。
    * 二重に立ち上がることはありません。
