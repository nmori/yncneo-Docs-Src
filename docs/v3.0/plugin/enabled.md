# プラグインの有効化

<!-- version-banner -->
!!! info ""
    ゆかコネNEO **v3.0** のドキュメントです。v2.3 をお使いの方は [v2.3 版のこのページ](../../v2.3/plugin/enabled.md) を、違いを知りたい方は [v2.3 から v3.0 への移行](../../mig/mig_neo_v3.0.md) をご覧ください。

プラグインを使うと、読み上げ・OBS連携・VRChat連携など、ゆかコネNEO の機能を増やせます。
どんなものがあるかは[プラグイン一覧](index.md)をご覧ください。

# 前半：使いたいプラグインを ON にする

## 手順

1. 左メニュー → **共通設定項目** → **プラグイン一覧** を開きます
   （画面上部のクイックボタンの「プラグイン一覧」からも開けます）
2. 使いたいプラグインの **チェックを入れます**
3. **チェックを入れた時点で動きはじめます**（再起動は要りません）
4. 設定が要るプラグインは、名前の右の **「設定」** ボタンを押します

<!-- TODO(screenshot): images/plugin_enabled_p1.png は v2.3 時点。v3.0 のプラグイン一覧で撮り直す -->

!!! tip "使うものだけ ON にしましょう"
    ON のプラグインが多いほど処理が増えます。使っていないものはチェックを外してください。

!!! warning "v2.3 から移行した方へ"
    「v2.3設定を移行」では、**プラグインの ON / OFF は取り込まれません**。
    移行のあとにこの画面を開いて、使っていたものが入っているか確認してください。

## プラグインを新しく追加する

配布されている ZIP ファイルを、そのまま読み込めます。

1. プラグイン一覧の **「プラグインを追加」** を開きます
2. **「ZIP から追加」** を押して ZIP を選びます（画面に ZIP を**ドラッグ＆ドロップ**してもかまいません）
3. 内容を確かめて **「追加する」** を押します
4. 一覧に出てくるので、選んで **「追加する」** を押すと使えるようになります

!!! warning "読み込んだだけでは動きません"
    ZIP を読み込むと一覧に名前が並びますが、その時点ではまだ動いていません。
    用途と前提条件を見てから「追加する」を押してください。**ゆかコネNEO の再起動は要りません。**

!!! Info "うまくいかないとき"
    * ZIP の中身がプラグインとして見つからないときは、何が入っていたかが表示されます。
      プラグインは **DLL ファイルが入ったフォルダ**が必要です。
      フォルダが二重になっていたり、説明書や画像が一緒に入っていてもかまいません。
    * ゆかコネNEO を Program Files など書き込めない場所に入れている場合は、
      コピー先のフォルダが開くので、そこへ手でコピーしてください。

!!! danger "v3.0 では .NET 10 対応のプラグインが必要です"
    v2.3（.NET Framework 4.8）向けにビルドされたプラグインは、**v3.0 では読み込めません**。
    公式配布のプラグインはすべて対応済みですが、
    自作したもの・個人からもらったものは、配布元に v3.0 対応版を出してもらってください。
    → [v2.3 から v3.0 への移行](../../mig/mig_neo_v3.0.md)

## プラグインが動かないときの確認順

| 順番 | 確認すること |
|:--|:--|
| 1 | プラグイン一覧に**名前が出ているか**（出ていなければ、読み込まれていません） |
| 2 | **チェックが入っているか** |
| 3 | 「設定」ボタンから開く画面で、**必要な項目が埋まっているか** |
| 4 | ほかのプラグインの影響を受けていないか（**処理は一覧の上から順**です） |
| 5 | 左メニュー → トラブルシュート → **動作チェック** で赤い項目がないか |

# 後半：もう少し細かい話

## 「有効化」と「読み込み（ロード）」の違い

この 2 つは別ものです。

| | 何をするか | どこで設定するか | 再起動 |
|:--|:--|:--|:--|
| **読み込み（ロード）** | 起動時にプラグインをメモリに読むかどうか | プラグイン設定ツール（`YNCNEO_Config.exe`。スタートメニューでは「メンテナンスツール」） | 要る |
| **有効化** | 読み込まれたプラグインを使うかどうか | プラグイン一覧のチェックボックス | 要らない |

**読み込んでいないプラグインは、一覧にも出てきません。**
一覧に名前が無いときは、まず読み込み設定を見てください。

### 読み込み設定を変える

1. 左メニュー → **トラブルシュート** → **トラブルシュート** を開きます
2. **「プラグイン編集」** を押します
3. 「いったんこのアプリを終了します。よろしいですか？」と聞かれるので **OK**
4. プラグイン設定ツール（`YNCNEO_Config.exe`）が開きます。
   スタートメニューの **「メンテナンスツール」** と同じものです
5. 読み込むプラグインにチェックを入れて保存します
6. ゆかコネNEO を立ち上げ直します

<!-- TODO(screenshot): images/plugin_enabled_p2.png は v2.3 時点。v3.0 のプラグイン設定ツールで撮り直す -->

!!! Info "本体はいったん終了します"
    読み込み設定は起動時にしか効かないため、このツールを開くときに本体を終了します。
    作業中の設定は終了時に保存されます。

!!! tip "使わないものを外すと軽くなります"
    読み込まないようにすると、起動が速くなり、メモリの消費も減ります。

## 処理の順番

プラグインは、**一覧の上から順に処理されます**。

たとえば辞書プラグインが置き換えた結果は、その下にあるプラグインに渡ります。
逆に、辞書より上にあるプラグインは、置き換える前の文字を見ます。

「先に効かせたいもの」を上に置いてください。
くわしくは[プラグインの動作](../design/plugin_rule.md)をご覧ください。

## 表示タイミングとの関係

字幕の保持時間が過ぎると、プラグイン側にも「消して」という指示が出ます。
文字を消さずに残したい場合は、[字幕のタイミング](../startup/startup_basic.md)で保持時間を最大にしてください。

## v3.0 の設定画面について

v3.0 では、**40 本以上のプラグインで設定画面が新しくなりました**。

* 見た目がすべてのプラグインで揃いました
* **表示言語に合わせて日本語・英語などで出ます**（v2.3 は「Slack設定 (Setting)」のように 1 つの文に詰め込んでいました）
* 「何を入れる欄なのか」「空のままだとどうなるのか」の説明が付きました
* **下書き方式**になりました。触った項目だけを覚えていて、閉じるときに
  **「適用」「破棄」「続ける」** の 3 択が出ます
* 規則の表（正規表現・ホットキー・効果音など）は共通の部品になりました。
  ファイルの形式は v2.3 と同じなので、**v2.3 に戻しても読めます**

!!! Info "新しい画面が開かないとき"
    従来の画面が逃げ道として残してあります。新しい画面を開けなかった場合は、そちらが開きます。

!!! Info "表の編集で気をつけること"
    表のあるページから別のページに切り替えると、その時点で表が書き出されます。
    「適用」の前に「キャンセル」で戻したいときは、表のページを離れる前に操作してください。
