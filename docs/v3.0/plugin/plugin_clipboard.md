## このプラグインで出来ること

* **音声認識結果のクリップボード転送**：確定したテキストを自動的にクリップボードに送信
* **高度な自動入力機能**：特定のアプリケーションに直接テキストを自動入力
* **双方向クリップボード連携**：クリップボードからゆかコネNEOへの受信も可能
* **話者名付き転送**：認識したテキストに話者名を自動付加
* **ウィンドウ指定機能**：対象アプリケーションを指定した確実な入力

## 有効化

* 上のタブ **プラグイン** → **プラグインを追加** でこのプラグインを選んで **追加する** を押します（一覧の **使う** が ON になります）。→ [プラグインの有効化](enabled.md)

## 設定

プラグイン一覧で、このプラグインの名前の右にある **「設定」** を押すと開きます。

!!! info "閉じるときの 3 択"
    設定は**下書き**として持たれ、「OK」か「適用」を押すまで動いているプラグインには効きません。
    変更したまま閉じようとすると「変更が保存されていません」と聞かれ、**［はい］保存して閉じる／［いいえ］破棄して閉じる／［キャンセル］閉じるのをやめる** から選べます。

字幕をクリップボードへコピーし、指定した入力欄へ貼り付けます。

![クリップボード連携の設定 - 送る](images/v30/clipboard_1.png)

| 項目 | 説明 |
|:--|:--|
| ☑ 字幕をクリップボードへコピーする | 既定：OFF |
| コピーする字幕 | 選択肢：母国語／翻訳 1／翻訳 2／翻訳 3／翻訳 4／母国語 + 翻訳 1。既定：母国語 |
| ☑ 話した人の名前も入れる | 既定：OFF |
| ☑ 改行をなくして 1 行にする | 既定：OFF |

**貼り付け先**　コピーした字幕を貼り付ける入力欄です。

| 項目 | 説明 |
|:--|:--|
| 「貼り付け先を選ぶ」ボタン | 押したあと、貼り付けたい入力欄にカーソルを合わせて F2 キーを押してください。 |
| ☑ 貼り付け先へ自動で貼り付ける | 既定：OFF |
| ☑ 貼り付けたら Enter も送る | 既定：OFF |
| ☑ 前に貼ったものを置き換える | オフにすると、話すたびに後ろへ追加していきます。（既定：OFF） |

**受け取る**

| 項目 | 説明 |
|:--|:--|
| ☑ クリップボードの文字を取り込む | ほかのソフトでコピーした文字が、そのまま字幕になります。（既定：OFF） |

### 補足

* 「貼り付け先」の **「貼り付け先を選ぶ」** を押したあと、貼り付けたい入力欄にカーソルを合わせて **F2** キーを押すと、貼り付け先が決まります。
* 決めた貼り付け先は「現在の貼り付け先」に表示されます。**「貼り付け先へ自動で貼り付ける」** を ON にすると、コピーするたびに貼り付けます。

## 高度な使用例

### 1. ライブ配信でのコメント自動入力
```
設定：
- コピーする字幕：母国語
- 貼り付け先へ自動で貼り付ける：ON
- 貼り付けたら Enter も送る：ON
- 貼り付け先：配信ソフトのコメント欄を指定
```

### 2. 翻訳結果の文書作成
```
設定：
- コピーする字幕：母国語 + 翻訳 1
- 話した人の名前も入れる：ON
- 前に貼ったものを置き換える：OFF（後ろへ追加）
- 貼り付け先：テキストエディタを指定
```

### 3. チャットアプリケーション連携
```
設定：
- コピーする字幕：翻訳 1
- 貼り付け先へ自動で貼り付ける：ON
- 貼り付けたら Enter も送る：ON
- 改行をなくして 1 行にする：ON（チャット用）
```

### タイミング制御
* クリップボード設定後の待機：50ms
* ウィンドウフォーカス後の待機：250ms
* 段階的なキー送信で確実な入力を実現

## トラブルシューティング

### 自動入力が失敗する場合
1. **ウィンドウ指定の確認**：「貼り付け先を選ぶ」ボタンで正しい入力欄を選択
2. **アプリケーション権限**：管理者権限で実行が必要な場合あり
3. **入力フォーカス**：対象アプリがアクティブになっているか確認

### クリップボードが更新されない場合  
1. **Windows設定**：クリップボード履歴が有効になっているか確認
2. **他アプリとの競合**：クリップボード管理ツールとの競合を確認
3. **権限問題**：セキュリティソフトによるクリップボードアクセス制限
