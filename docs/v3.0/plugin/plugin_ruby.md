## このプラグインで出来ること

* 認識後の文章に付けるルビ（かな、もしくはピンイン）を、形態素解析（MeCab）で作ります
* 読み方を直したい言葉を「ルビの単語帳」に登録し、MeCab のユーザー辞書を作り直せます

!!! Info "ルビを字幕に描くのは本体です (v3.0.0 beta 23～)"
    * ルビを出すかどうかは、本体の「レイアウトデザインの選択」→「見た目を調整する」→「表示内容」にある **「ルビの表示（対応している場合）」** で切り替えます。詳しくは [標準設定項目の「表示内容」](../startup/startup_basic.md#display-content) をご覧ください。
    * このプラグインは、本体に頼まれて**字幕の文字から語と読みの組を作る係**です。字幕の HTML を書き換えることはしません。
    * UDトークや [/api/input の Morph](../tech/tech_api_neo.md) から読みが届いた文は、このプラグインを使わずにその読みでルビが付きます。このプラグインが作るのは、読みが届かなかった日本語・中国語の文の分です。
    * このプラグインを無効にすると、読みが届かなかった文にはルビが付きません。

!!! warning "beta 22 以前からお使いの方へ"
    「ルビの表示（対応している場合）」の既定は OFF です。beta 23 に上げて最初に起動したときだけ、このプラグインを有効にしていた方は自動で ON になります（それまでと同じ見た目のままです）。

!!! warning "ルビはNEOの表示レイアウト内のみ有効で、OBS転送などには反映されません"

##　有効化

![置換](images/plugin_ruby_p1.png)

* プラグインを使うチェックをONにしてください。

## 設定

プラグイン一覧で、このプラグインの名前の右にある **「設定」** を押すと開きます。

!!! info "閉じるときの 3 択"
    設定は**下書き**として持たれ、「OK」か「適用」を押すまで動いているプラグインには効きません。
    変更したまま閉じようとすると「変更が保存されていません」と聞かれ、**［はい］保存して閉じる／［いいえ］破棄して閉じる／［キャンセル］閉じるのをやめる** から選べます。

読み方を直したい言葉を並べます。ここに書いた読みが、ルビに使われます。ルビを字幕に出すかどうかは、本体の「表示内容」にある「ルビの表示」で切り替えます。

![ルビ振りの設定 - 単語](images/v30/ruby_1.png)

**ルビの単語帳**（表）

列：漢字／まちがった読み／正しい読み

「正しい読み」はカタカナで書きます (半角カタカナは全角に直します)。OK か適用を押すと、MeCab のユーザー辞書を作り直します。

表の右上の **「行を足す」** で行を増やします。行の右端のボタンは ▲▼＝1 つ上へ／下へ、＋＝この下に足す、×＝この行を消す です。**「保存する」** はいまの中身を CSV へ書き出します（控え用）。**「読み込む」** は CSV から読み込んで、いまの中身と入れ替えます。

## 使うとき

1. このプラグインを有効にします。
2. 本体の「レイアウトデザインの選択」→「見た目を調整する」→「表示内容」で、**「ルビの表示（対応している場合）」** を ON にします。
3. 音声認識した日本語・中国語の字幕に、ルビが付いて表示されます。

!!! Info "ルビが出ないとき"
    * 「ルビの表示（対応している場合）」が OFF になっていないか確かめてください。
    * ルビに対応していないテンプレートでは表示されません。
    * ルビを作るのが間に合わなかった文（1.5 秒まで待ちます）は、ルビ無しで表示されます。
