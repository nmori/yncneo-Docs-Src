## このプラグインで出来ること

* 起動時に関連するツールも起動できます

!!! Info "こういう時に使おう"
    * いくつも使うツールがある場合に活用しましょう

## 有効化

* 上のタブ **プラグイン** → **プラグインを追加** でこのプラグインを選んで **追加する** を押します（一覧の **使う** が ON になります）。→ [プラグインの有効化](enabled.md)

## 設定

プラグイン一覧で、このプラグインの名前の右にある **「設定」** を押すと開きます。

!!! info "閉じるときの 3 択"
    設定は**下書き**として持たれ、「OK」か「適用」を押すまで動いているプラグインには効きません。
    変更したまま閉じようとすると「変更が保存されていません」と聞かれ、**［はい］保存して閉じる／［いいえ］破棄して閉じる／［キャンセル］閉じるのをやめる** から選べます。

ゆかコネの起動に合わせて、ほかのアプリも起動します。

![いっしょに起動の設定 - いっしょに起動](images/v30/startup_1.png)

| 項目 | 説明 |
|:--|:--|
| 起動するアプリ | 1 行に 1 つ書きます。書き方は "実行ファイル" 引数 です。引数の {http} と {ws} は、本体が使っているポートへ置き換わります。 |
| 「ファイルを選んで追加」ボタン | 選んだファイルが、上の一覧の最後に追加されます。ショートカット (.lnk) を選ぶと、リンク先の実行ファイルに置き換えます。 |
| 「今すぐ起動」ボタン | — |
| 「起動したものを閉じる」ボタン | — |

**起動方法**

| 項目 | 説明 |
|:--|:--|
| ☑ 同じ名前のものが動いていたら起動しない | 既定：OFF |
| ☑ ウィンドウを表示して起動する | オフにすると、最小化した状態で始まります。（既定：OFF） |
| ☑ 管理者として起動する | 起動のたびに Windows の確認が出ます。（既定：OFF） |
| ☑ cmd 経由で起動する | 関連付けやショートカット (.lnk など) を使いたいときにオンにします。（既定：OFF） |

**終了時**

| 項目 | 説明 |
|:--|:--|
| ☑ ゆかコネを閉じたら、起動したものも閉じる | 強制終了せず、ウィンドウに閉じるよう要求します。（既定：OFF） |
