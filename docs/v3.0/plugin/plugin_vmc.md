## このプラグインで出来ること

* ばもきゃに対応した信号を出すことができます。

!!! Info "謝辞"
    * 連携先ソフトウェアの開発者は[あきら様](https://twitter.com/sh_akira)です。

!!! Warning "うまく動かないときのレポートについて"
    * 当方が連携機能をつかって勝手に連携しているだけです。<br>あきら様に直接問い合わせをしないでください。

## 有効化

* 上のタブ **プラグイン** → **プラグインを追加** でこのプラグインを選んで **追加する** を押します（一覧の **使う** が ON になります）。→ [プラグインの有効化](enabled.md)

## 設定

プラグイン一覧で、このプラグインの名前の右にある **「設定」** を押すと開きます。
画面は **3 ページ**に分かれていて、左の一覧で切り替えます（受け取る／送り先／キャリブレーション）。

!!! info "閉じるときの 3 択"
    設定は**下書き**として持たれ、「OK」か「適用」を押すまで動いているプラグインには効きません。
    変更したまま閉じようとすると「変更が保存されていません」と聞かれ、**［はい］保存して閉じる／［いいえ］破棄して閉じる／［キャンセル］閉じるのをやめる** から選べます。

### 受け取る

ばもきゃからのメッセージを受信します。

![ばもきゃ連携の設定 - 受け取る](images/v30/vmc_1.png)

| 項目 | 説明 |
|:--|:--|
| 受け取るポート | 1～65535番。既定：39538 |
| 「接続」ボタン | — |
| 「切断」ボタン | — |

### 送り先

字幕やメッセージの送り先です。

![ばもきゃ連携の設定 - 送り先](images/v30/vmc_2.png)

**ばもきゃへ**

| 項目 | 説明 |
|:--|:--|
| 送り先 (IP) | 既定：「127.0.0.1」 |
| 送り先のポート | 1～65535番。既定：39539 |

**字幕の送り先**

| 項目 | 説明 |
|:--|:--|
| 送り先 (IP) | 既定：「127.0.0.1」 |
| 送り先のポート | 1～65535番。既定：39541 |
| ☑ 母国語を送る | 既定：OFF |
| ☑ 翻訳を送る | 既定：OFF |

> 字幕は /YNC/Text/Native と /YNC/Text/Trans1〜4 へ、文字として送ります。

### キャリブレーション

話した言葉をきっかけに、キャリブレーションを始めます。

![ばもきゃ連携の設定 - キャリブレーション](images/v30/vmc_3.png)

| 項目 | 説明 |
|:--|:--|
| ☑ 通常のキャリブレーションを使う | 既定：OFF |
| その起動フレーズ | 既定：「VRキャリブレーション開始」 |
| ☑ MR キャリブレーションを使う | 既定：OFF |
| その起動フレーズ | 既定：「MRキャリブレーション開始」 |
| ☑ MR 床キャリブレーションを使う | 既定：OFF |
| その起動フレーズ | 既定：「MR床キャリブレーション開始」 |

## 使い方
1. ばもきゃ通信をするツールを起動します
2. 設定の「受け取る」ページで「接続」をおして、VMC参加をおします。
3. 条件がそろえば、随時通信を送ります。
