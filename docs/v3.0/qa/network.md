# 外部と通信をしたくない場合

<!-- version-banner -->
!!! info ""
    ゆかコネNEO **v3.0** のドキュメントです（このページの画面の名前は v3.2.3 以降のものです）。

ゆかコネは、音声認識と翻訳のエンジンを**自分で選べる**のが良いところです。
そして、**あなたが選んだところとだけ通信します**。選んでいない会社へ、声や字幕の文字を送ることはありません。

このページでは、機能ごとに「どこと通信するか」をまとめています。
声も文字も外に出したくないときは、最後の「[PC の中だけで動かす](#local-only)」の手順をどうぞ。

!!! tip "いまの送り先は画面で確かめられます"
    上のタブ **ホーム** → **いまの状態** の **送り先** の行に、「声: … ／ 文字: …」と出ます。
    右の **ⓘ** を押すと、機能ごとの送り先が出ます。
    **音声と翻訳** → **音声の入れ方** の上にある **送り先を見る** でも同じものが見られます。

## 声（音声認識）

| 選んだ音声認識 | 声の送り先 |
|:--|:--|
| ブラウザ音声認識（Chrome） | Google |
| ブラウザ音声認識（Edge） | Microsoft |
| Windows 11 音声認識 | Microsoft |
| UDトーク | UDトークのサービス（UDトークの規約によります） |
| オフライン認識（VOSK・Whisper・Haas など） | PC の中だけ |
| Parapper・Whisper 連携 | PC の中だけ |

* PC の中だけで動くものも、**モデルを初めてダウンロードするときだけ**通信します。
* Windows 11 音声認識は、部品の名前に「Offline」と付いたものがありますが、中身はオンラインの認識です。

## 文字（翻訳）

| 選んだ翻訳エンジン | 文字の送り先 |
|:--|:--|
| 共用翻訳 | ゆかコネの翻訳サーバ（Google Cloud Run） |
| DeepL・Google・Microsoft・Gemini・Claude・OpenAI・Papago など | 選んだ会社 |
| 翻訳しない | どこにも送りません |
| ブラウザ翻訳・Parapper 翻訳 | PC の中だけ |
| オフライン翻訳・PLaMo 3 翻訳（オフライン） | PC の中だけ（初めてのときだけ、モデルと実行環境を GitHub と Hugging Face から取ります） |

!!! info "「訳せなかったときの代わりの翻訳」も送り先になります"
    翻訳に失敗した文は、代わりの翻訳エンジンで訳し直します。最初は **共用翻訳** になっているので、
    オフライン翻訳を選んでいても、訳せなかった文は共用翻訳へ送られます。
    下の「PC の中だけで動かす」を使うと、この代わりの翻訳も止まります。

## プラグイン

プラグインは、**オンにしたものだけ**が通信します。

| プラグインの種類 | 通信先 |
|:--|:--|
| Discord・YouTube・Twitch・字幕共有（Pusher）・Webhook 系・AI 系 など | それぞれの連携先 |
| 辞書・ルビ・OBS 連携・VRChat 連携・読み上げ（PC に入れた声）・ファイル出力 など | PC の中だけ |

## 字幕テンプレート

字幕テンプレートは全部ゆかコネに入っていて、ふだんは外から何も読みません。
次のときだけ、書体を Google Fonts から読みます。

* リリックモーションを使うとき
* 字体に Web フォントを選んだとき
* 表示効果プラグインのフォントの強調を使うとき

## 起動したときの通信

起動したときは、次の通信をします。**声や字幕の文字は送りません。**

| いつ | 何のため | 通信先 |
|:--|:--|:--|
| 毎回 | 時刻合わせ（支援の期限の確認に使います。返事の時刻を読むだけです） | Cloudflare → Google → nmori.github.io の順に 1 つ |
| 毎回 | ようこそ画面のお知らせの取得 | machanbazaar.com |
| 支援コードを登録しているとき | 支援の確認 | 支援の中継（Cloudflare Workers） |
| DeepL の自分のキーを使うとき、または支援 Tier 3 以上のとき | 用語集の準備 | DeepL |
| 更新通知プラグインがオンのとき | 新しい版の確認 | nmori.github.io |
| PLaMo 3 翻訳に同意しているとき | ライセンスの改定の確認（12 時間に 1 回まで。送るのはモデルの置き場の名前だけ） | Hugging Face |

このほか、**不具合を知らせる**のボタンを押したときだけ、報告を Discord へ送ります。

## PC の中だけで動かす { #local-only }

声も文字もこの PC の外に出したくないときは、次のどちらかで設定します。

### 「このパソコンの中だけで動かす」ボタン

1. 上のタブ **音声と翻訳** → **音声の入れ方** を開きます。
2. 上にある **このパソコンの中だけで動かす** を押します。
3. 翻訳のしかたを選びます。
    * **翻訳しない (字幕だけ)**
    * **オフライン翻訳で訳す**
    * **PLaMo 3 翻訳で訳す**

音声認識がオフライン認識になり、翻訳も PC の中で行う設定にまとめて切り替わります。**訳せなかったときの代わりの翻訳も止まります。**

### はじめての設定で選ぶ

はじめての設定の手順 2 で **このパソコンの中だけで認識する** を選ぶと、「翻訳もこのパソコンの中でしますか？」と聞かれます。
**翻訳しない (字幕だけ)**／**オフライン翻訳で訳す**／**PLaMo 3 翻訳で訳す** を選ぶと、上のボタンと同じ設定になります（**いまのまま** を選ぶと、翻訳の設定は変えません）。

!!! tip "モデルは先に取っておきましょう"
    オフライン認識・オフライン翻訳・PLaMo 3 は、初めて使うときにモデルをダウンロードします。
    ネットを止める前に、一度使ってモデルを取っておいてください。

!!! info "通信を完全に止めたいとき"
    * Windows ファイアウォールで、`YNC_Neo.exe` の外向きの通信を止めてください。
    * `127.0.0.1`（この PC の中の通信）は止めないでください。字幕ウィンドウや配信ソフトへの表示に使っています。
    * 起動したときの通信（時刻合わせ・お知らせ）ができなくても、ゆかコネは動き続けます。
