## 概要

サポートレベルは下記のようになります。

|Lv |状態       |機能追加、改良|サポート |
|---|-----------|--------------|---------|
| S | 開発中    |◎            |◎       |
| A | 運用中    |〇            |◎       |
| B | 保守      |△            |〇       |
| C | 安定      |－            |〇       |
| D | アーカイブ|－            |△       |
| Z | 廃止      |－            |－       |

!!! Info "これは確定ではありません"
    * コミュニティへのリアクションによりレベルが上がったり下がったりします。
    * 一度 D まで下がった場合は、基本的にレベルがあがることはありません。
