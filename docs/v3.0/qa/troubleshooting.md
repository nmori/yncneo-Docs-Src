# こんなときは

<!-- version-banner -->
!!! info ""
    ゆかコネNEO **v3.0** のドキュメントです。v2.3 をお使いの方は [v2.3 版のこのページ](../../v2.3/qa/troubleshooting.md) を、違いを知りたい方は [v2.3 から v3.0 への移行](../../mig/mig_neo_v3.0.md) をご覧ください。


!!! Notice "まずは"

    * 一息おいてみましょう。
    * 直前に導入、削除、更新したものはありませんか？
    * 再起動しても直りませんか？

## OBSで字幕が出ない

!!! Note "OBSを更新していませんか？ "

    * OBS v28に更新した時点で、OBS-Websocketのバージョンが変わっています。
    * version 4 と version 5 は別ものです。使うものが異なります。
    * version 4 の場合は [こちらの説明](../plugin//plugin_OBS.md)をみて導入してみてください
    * version 5 の場合は [こちらの説明](../plugin//plugin_OBS5.md)をみて導入してみてください

## 起動しない

!!! Note "上書きアップデートしましたか？ "

    * 通常は上書きアップデートで問題ありませんが、お使いの環境によってうまくいかないことがあります
    * [再インストール](reinstall.md)をお試しください

## 音声認識画面がすぐ消える

!!! Note "通信できていない場合があります "

    * 通信に必要なポートが開けなかった可能性があります。通常は TCP/11900番（と 11901番）を使用します。使用中の場合は自動的に別の番号に変わります
    * 通信を阻害する他のソフトウェアをみつけたら、停止させたうえで起動してください
    * ゆかコネNEOが多重起動しているとうまく起動できないことがあります。
    * Windowsが不安定になっている場合があります。再起動してみてください。
    * セキュリティソフトが通信を阻害している場合があります。除外設定してみてください。

## 音声認識がぶつぶつきれる

!!! Note "音声がうまく取れていない可能性があります "

    * RTX Voiceなどのフィルタソフトが強めにかかっていませんか
    * AGC機能などで音量がふらふらしていませんか
    * 周りのノイズと声の差が小さいと話し始めが欠ける場合があります
    * ブラウザ音声認識の場合は、ノイズを取りすぎても話始めが欠けることがあります

!!! Note "連続発話のチェックがはずれていませんか"

    * 連続発話のチェックがOFFになっている場合、音声認識がおわってから次の認識が始まるまでに一瞬音声認識が止まります。
    * 立て続けに話している場合に、文の始めが欠けることがあります。連続発話モードをONにしてみてください。

!!! Note "オフライン認識で、文が途中で確定していませんか"

    * v3.0.18 から、オフライン認識は話し手の間を見て 1 文ずつ確定します。息継ぎで文が割れるときは、オフライン認識の画面の「⚙ 設定」→ **「区切る間」** を長めに、字幕を早く出したいときは短めにしてください。
    * v3.0.17 以前は、長く話すと数秒ごとに途中で確定することがありました。最新版に更新してください。
    → [文を区切る間](../startup/startup_asr.md#offline-sentence-pause)

## 句読点が二重に付く・付かない

!!! Note "句読点の設定が2か所で ON になっていませんか"

    * ゆかコネNEO の「音声の入れ方」→「オプション」の **「AIモデルで句読点を打ちこむ（日本語のみ）」** と、オフライン認識の画面の **「句読点」** は別の設定です。
    * v3.0.17 から、音声の入れ方に「オフライン認識」を選んでいるあいだは、ゆかコネNEO 側は OFF になり、二重には付きません。オフライン認識では画面の「句読点」を使ってください。
    → [AIモデルで句読点を打ちこむ](../startup/startup_basic.md#punctuation-restore)

!!! Note "句読点が付かない文ではありませんか"

    * 付けるのは**日本語の確定文で、まだ句読点の無いもの**だけです。途中経過・もう句読点のある文・ほかの言語の文・API から送った文には付けません。
    * 初めて ON にしたときは、モデル（約 44MB）のダウンロードが終わるまで句読点を付けずに送ります。

## 音声認識されない・字幕が出ない

!!! Note "正しいマイクが刺さっていますか"

    * ブラウザの設定で設定されてるマイク設定が変更されていることがあります
    * 話しかけているマイクと音声認識されているマイクが異なっていることがあります

!!! Note "ミュートボタンが押されていませんか"

    * ゆかコネNEO上側のマイクボタンがミュートになっていませんか（点滅していませんか）

!!! Note "ゲインはあっていますか"

    * マイクの音量が大きすぎて音が割れていませんか
    * マイクの音量が小さくなっていませんか
    * 周りがうるさくて音声とノイズの聞き分けがむずかしくなっていませんか

!!! Note "適切な音声認識エンジンが選ばれていますか"

    * たとえば、ゆかりねっとを併用する設定なのにゆかりねっとが起動していないなどありませんか

!!! Note "ブラウザ音声認識が「接続中」のまま止まっていませんか（Chrome）"

    * 新しい Chrome では、音声認識画面からゆかコネNEO へつなぐのに「このデバイス上のアプリ」「ローカル ネットワーク」へのアクセスの許可が要ります。
    * 音声認識画面に「ゆかコネNEO への接続を許可してください」「ゆかコネNEO への接続がブラウザに止められています」と出ていたら、許可してください。
    → [Chrome の接続の許可](../startup/startup_asr.md#chrome-local-network)

!!! Note "音声認識画面で選んでいるマイクは合っていますか"

    * 音声認識画面の「マイク」の欄で、第1入力・第2入力に使うマイクを選べます。入力レベルのメーターが動いているか確かめてください。
    * 「マイクの入力が完全に無音です。」と出ているときは、マイクのミュートや OS の録音設定を確認してください。
    → [ブラウザ音声認識の画面でできること](../startup/startup_asr.md#browser-recognition)

!!! Note "オフライン認識のモデルのダウンロードを断っていませんか"

    * オフライン認識の画面の「モデル」の状態が「ダウンロードを取りやめました / Download cancelled」になっていたら、ダウンロードの確認で「いいえ」を選んでいます。もう一度「取得」を押して「はい」を選んでください。
    * 「保存先が見つかりません / Model folder not found」と出るときは、モデルの保存先にしたドライブ（外付けなど）が見つかりません。ドライブをつなぐか、ゆかコネNEO の「モデルの保存先と管理」で保存先を変えてください。
    → [モデルの保存先と管理](../startup/startup_option.md#model-storage)

## 翻訳の精度がでない

!!! Note "共用翻訳サーバをつかっていませんか "

    * 共用翻訳サーバは無料で提供していますが、文が短いケースなどでは翻訳精度が出ないことがあります
    * DeepL、GAS、Microsoft翻訳など、無料枠のある翻訳に切り替えるか、支援もしくは個人契約したAPIキーを使うなど、商用エンジンを使う手もあります。

!!! Note "翻訳にはパターン・語順があります "

    * 日本語で省きがちな主語などを入れないと翻訳があやふやになることがあります
    * 倒置や入り組んだ文体になっていると、翻訳が混乱し正しい結果になりません。
    * なるべくシンプルに分かりやすく話すことが重要です。

## 翻訳に失敗する

!!! Note "APIキーの設定はできていますか "

    * 個人契約したAPIキーを使う場合は、有効なキーが設定されていますか
    * クレジットカードが無効になっていたりしませんか

!!! Note "FANBOXのプロモーションキーは更新しましたか"

    * プロモーションキーは２ヶ月程度に１度更新されます。
    * FANBOXを更新していれば取得可能なので、最新のキーを入れてください

!!! Note "翻訳量を使い切っていませんか"

    * FANBOXの場合は、支援に応じて月利用上限があります。超えた場合は来月まで待つか、プランアップをご検討ください。
    * 個人でAPIを契約している場合でも、サイト設定側で月の利用上限が設定されている場合があります。

!!! Note "画面の下に「このままでは翻訳されません」と出ていませんか"

    * 「（エンジン名） の API キーが入っていないため、このままでは翻訳されません。」などと出たときは、そのエンジンに要るキーや接続先が入っていません。
    * お知らせの **「設定を開く」** を押すと「APIキーの設定」画面へ移れます。

!!! Note "利用条件の画面で「使わない」を押しませんでしたか"

    * PLaMo翻訳・みらい翻訳・みんなの自動翻訳＠TexTra・オフライン翻訳（無料）・PLaMo 3 翻訳（オフライン）は、選んだときに利用条件の画面が出ます。「使わない」を押すと、別のエンジン（オフライン翻訳・PLaMo 3 翻訳は共用翻訳、ほかは「翻訳しない」）に戻ります。
    * 使う場合は、もう一度一覧から選んで「同意して使う」を押してください。
    → [一覧から選んだときの同意](../startup/startup_option.md#engine-terms-consent)

## オフライン翻訳（無料）で訳されない

!!! Note "モデルの準備中ではありませんか"

    * 初めて使うときは、モデルのダウンロードと起動が済むまで、**ほかの翻訳エンジンで**訳します。画面の下のステータスバーに「オフライン翻訳 56%・残り約 20 秒」のような進み具合が出ているあいだは、お待ちください。
    * 英語⇔日本語以外の言語では、約 2.8GB のモデルをダウンロードします。

!!! Note "ライセンスの同意チェックは ON になっていますか"

    * 「APIキーの設定」画面のオフライン翻訳（無料）の欄で、同意のチェックが OFF だと、ダウンロードも翻訳もしません。

!!! Note "保存先のドライブはつながっていますか"

    * モデルの保存先を外付けドライブなどにしていて、そのドライブが見つからないときは、新しいモデルをダウンロードしません。
    → [オフライン翻訳（無料）](../startup/startup_option.md#offline-translation)

!!! Note "PLaMo 3 翻訳（オフライン）で、一部の言語だけ訳されない"

    * ポルトガル語・トルコ語・ウクライナ語など、PLaMo 3 が訳せない言語は、ほかの翻訳エンジンで訳します。
    * 同意のチェックやモデルの準備は、オフライン翻訳（無料）とは別です。「APIキーの設定」画面の PLaMo 3 翻訳（オフライン）の欄を確かめてください。
    → [PLaMo 3 翻訳（オフライン）](../startup/startup_option.md#plamo3-translation)

## ほかのPC・自作ツールから字幕を送れなくなった

!!! Note "v3.0.8 から、LAN からの操作にはトークンが要ります"

    * 別のPC（LAN）から字幕を送ったり設定を変えたりするには、「ネットワークの設定」画面の **「LAN からの操作に使うトークン」** が要ります。「コピー」で写して、送る側でヘッダー ``X-YNC-Token`` か URL の ``?token=…`` で付けてください。
    * ブラウザで開いたページから操作している場合、知らないページからの操作は断ります。そのページのアドレスを「Web許可ホスト」に書いてください。
    * Tailscale や hosts の別名でこの PC を開いているときは、その名前を「Web許可ホスト」に書いてください。

!!! Note "アクセス状況を見てみましょう"

    * 「ネットワークの設定」画面の **アクセス状況** に、直近 20 件の許可・拒否と理由（許可していない IP／許可していないホスト名／知らない Web ページから／トークンなし／トークン違い など）が出ます。
    → [アクセス状況](../startup/startup_option.md#access-log)・[本体内蔵API（アクセス制御について）](../tech/tech_api_neo.md#access-control)

## AIアシスタント（MCP）からつながらない

!!! Note "MCP サーバー プラグインの「接続の記録」を見てみましょう"

    * MCP サーバー プラグインの設定画面の **「接続の記録」** に、つながった・断った（理由つき）・呼ばれた記録が出ます。
    * ブラウザのページからつなぐときは、「ブラウザと上限」の「接続を許すページ (Origin)」にそのページが書かれているか確かめてください。
    * LAN やインターネット上のページからつなぐときは、接続キーが要ります。
    → [AIアシスタント（MCP）からゆかコネを操作する](../tech/tech_api_neo.md#mcp)

## v3.0 にしてからうまくいかない

!!! Note "設定が全部消えたように見える"
    v3.0 は設定の保存先フォルダ名が変わっています。初回起動で自動的に v2.3 の設定を探しますが、
    見つからなかった場合は、「設定保存・復元」→ **「v2.3設定を移行」** を押してください。
    → [設定の保存・復元](../startup/startup_profile.md)

!!! Note "移行したのに、次の起動で元に戻る"
    移行したあと、**設定画面で「適用」を押してから終了**してください。
    一部の設定は画面の保存経路を通らないと保存されません。

!!! Note "使っていたプラグインが一覧に出てこない"
    * **v2.3 向けにビルドされたプラグインは v3.0 では読み込めません。**
      公式配布のものは対応済みです。自作・個人配布のものは配布元に v3.0 対応版を依頼してください
    * 読み込み設定が外れている可能性もあります。トラブルシュート →「プラグイン編集」で確認してください
    * 「v2.3設定を移行」ではプラグインの ON / OFF を取り込まないので、入れ直しが要ることがあります
    → [プラグインの有効化](../plugin/enabled.md)

!!! Note "内蔵ブラウザを使う機能が動かない"
    v3.0 では CefSharp から **WebView2** に変わりました。WebView2 ランタイムが必要です
    （Windows 11 は標準、Windows 10 も Edge が入っていれば一緒に入っています）。
    対象は 内蔵ブラウザ／コメントスクリーン連携／ニコニコ生放送連携／clusterウェブトリガ です。
    ログイン状態は入り直しになることがあります。

!!! Note "設定項目が見つからない"
    「母国語と言語の表示」「フォント設定と配置」「色（表示色や背景色）」は左メニューから外れ、
    上のタブ **「字幕デザイン」→「デザイン」** の分類のタブ（文字／色／縁取り／表示／表記…）と **「詳しい調整」** の中に移りました。

    それでも見つからないときは、左メニューの **「設定をさがす」** に
    項目名（例：`保持時間`）を入れて Enter を押してください。

!!! Note "字幕が長く残る／間の字幕が飛ぶ"
    v3.0 では字幕が読み上げの終わりに合わせて消えます。その代償として、
    読み上げが遅れると字幕も遅れ、1 枠型のレイアウトでは待ちが 8 件を超えると間の字幕が飛びます。
    1 文ずつ確実に出したい場合は、**積み上げ型のレイアウト**にするか同期を切ってください（[読み上げ](../plugin/plugin_playvoice.md)の詳細設定 →「タイミングと連携」→「字幕の表示時間を、なるべく読み上げの長さに合わせる」）。
    → [読み上げ](../plugin/plugin_playvoice.md)

!!! Note "VRChat OSC の台本が逆に動く"
    v3.0 beta 7 で `TEXT` 行と素の行の送り先が入れ替わりました。
    「v2.3設定を移行」で書き直しの確認が出るので「はい」を選んでください。
    → [VRChat OSC連携](../plugin/plugin_vrchat_osc.md)

## ゆかコネNEOが起動しない

!!! Note "設定ファイルが破損した可能性があります "

    * 設定ファイルが破損した場合は、起動時にエラーが起きて立ち上がりません。
    * メンテナンスツール（`YNCNEO_Config.exe`）で設定を一度消してみてください。
      ゆかコネNEO の中からは トラブルシュート →「プラグイン編集」でも開けます

!!! Note "v2.1.122以降には救済メニューがあります"

    * 設定を消したあと、設定を戻すための機能が追加されています。
    * 設定をけしたら、SHIFTキーをおしたままゆかコネNEOを起動してください。過去の設定リストがでますので、うまく動いていた日のデータを復元してみてください。
