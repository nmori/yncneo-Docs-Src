# ドキュメントのバージョン

ゆかコネNEO のドキュメントは、**v2.3 向け**と **v3.0 向け**に分かれています。
いま使っているバージョンに合ったほうを読んでください。

## 自分のバージョンを確かめる

ゆかコネNEO の画面いちばん上（タイトルバー）に、`YukarinetteConnector NEO v◯.◯.◯` と出ています。
そこの数字が `2.3` で始まっていれば v2.3、`3.0` で始まっていれば v3.0 です。

## 2 つのバージョンの違い

| | v2.3 | v3.0 |
|:--|:--|:--|
| 位置づけ | 安定版・最新版 | 先行開発版（ベータ） |
| 動かすのに必要なもの | Windows 10 / 11 | Windows 10 / 11 ＋ WebView2 ランタイム（Windows 11 なら標準で入っています） |
| インストール後の容量 | — | 展開後でおよそ 1GB（内蔵ブラウザが WebView2 になったぶん、**v2.3 より小さくなります**） |
| 設定画面 | 左メニューに項目が並ぶ | 左メニューを整理し、見た目の設定は「レイアウトデザイン」に集約 |
| プラグインの設定画面 | プラグインごとにバラバラ | 共通の形に統一（表示言語の切り替えに対応） |
| ドキュメント | 凍結（重大な誤りのみ修正） | 更新中 |

!!! tip "どちらを使うか迷ったら"
    配信など「失敗できない用途」で毎日使っているなら **v2.3** のままで問題ありません。
    v3.0 はまだベータで、[ダウンロード](download.md)ページでも「先行開発版」として配布しています。
    新しい読み上げ機能や整理された設定画面を試したい方は v3.0 をどうぞ。

## 古い URL について

v2.3 / v3.0 に分ける前の URL（`/startup/...`、`/plugin/...` など）は、
**v3.0 のページへ自動で転送**されます。ブックマークや配信の概要欄に貼ってあるリンクは
そのままで開けますが、v2.3 をお使いの場合は転送先のページ上部にある
「v2.3 版のこのページ」から読み替えてください。
